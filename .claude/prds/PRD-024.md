# PRD — Inbox with Claimable Rewards
**ID:** PRD-024
**Sprint block:** BLOCK 3
**Priority:** P1
**Author:** PM Agent
**Date:** 2026-04-26

## Problem / Why
Players have no in-app inbox. The HUD shows a mail icon (placeholder). The economy designer confirmed: an inbox only earns its build cost if it delivers claimable rewards (coins, gems) — not just passive notifications. This drives D1/D7 retention via "claim waiting" hooks.

## Success metrics
- Players can open inbox from HUD mail icon
- Inbox shows unread count badge on HUD icon (> 0 only when items exist)
- Players can claim coin/gem rewards from inbox items
- Claimed rewards credit to profile immediately

## Scope (in)
**DB table:**
- `inbox_items(id UUID PK, user_id UUID FK auth.users ON DELETE CASCADE, type TEXT DEFAULT 'reward' CHECK(IN('reward','announcement','event')), title TEXT NOT NULL, body TEXT, reward_coins INT NOT NULL DEFAULT 0, reward_gems INT NOT NULL DEFAULT 0, claimed BOOLEAN NOT NULL DEFAULT false, created_at TIMESTAMPTZ DEFAULT now(), expires_at TIMESTAMPTZ)`
  - RLS: authenticated SELECT/UPDATE (claim) own rows; INSERT via service_role only
  - Index on (user_id, claimed, created_at DESC)

**Seed data:** Insert 2 welcome inbox items for all existing users via migration:
  - "🎉 Welcome Bonus" — 100 coins + 5 gems, type='reward'
  - "📺 First Episode Free" — 0 coins, 0 gems, type='announcement', body explaining the free episode system

**Edge Functions:**
- `claim-inbox-reward` — POST + JWT auth
  - Body: `{ item_id }`
  - Validates item belongs to user, not already claimed, not expired
  - Marks claimed=true
  - Credits reward_coins to profiles.coins, reward_gems to profiles.gems (atomic UPDATE)
  - Returns `{ claimed: true, coins_earned: number, gems_earned: number }`
- `send-inbox-message` — POST + service_role only
  - Body: `{ user_id?, all_users?: boolean, title, body, type, reward_coins?, reward_gems?, expires_in_days? }`
  - Inserts inbox_items for one user or all users (if all_users: true, query auth.users)
  - Returns `{ sent: number }`

**Flutter:**
- `lib/features/inbox/domain/inbox_item.dart` — InboxItem model
- `lib/features/inbox/data/inbox_service.dart` — fetchItems(), claim(itemId)
- `lib/features/inbox/application/inbox_provider.dart`
  - `inboxItemsProvider` (FutureProvider, refreshes on claim)
  - `unreadCountProvider` (derived: count where claimed==false)
- `lib/features/inbox/presentation/inbox_screen.dart`
  - Full-screen modal (showModalBottomSheet, isScrollControlled: true, height 80%)
  - Header: "📬 Inbox" title + close button
  - ListView of InboxItemCard widgets
  - InboxItemCard: icon by type (🎁 reward, 📢 announcement, ⚡ event), title, body, reward chips (🪙N if coins>0, 💎N if gems>0), "Claim" button (pinkFull) or "Claimed ✓" (dimmed)
  - Empty state: "All caught up! Check back soon."
- `lib/shared/widgets/hud.dart` — wire mail icon: tap → `InboxScreen.show(context, ref)`; badge reads `unreadCountProvider`, hidden when count == 0, shows count when > 0 (using pink token, textCol text)

## Scope (out)
- No push notification trigger for new inbox items (push already handled by PRD-017)
- No inbox pagination (LIMIT 50 is fine for MVP)
- No delete/dismiss of inbox items by user
- No rich media in inbox items

## Economy notes
Welcome bonus (100 coins + 5 gems) gives new players a soft-currency buffer that encourages first episode unlock. Expirable reward items create urgency ("claim before it expires") — key D1 hook.
