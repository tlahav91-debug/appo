# PRD — Meta World Tab
**ID:** PRD-023
**Sprint block:** BLOCK 3
**Priority:** P1
**Author:** PM Agent
**Date:** 2026-04-26

## Problem / Why
The Meta tab currently shows a "Coming Soon" placeholder. Meta World is a cosmetic customisation layer (Room, Outfit, Mood) that gives players a personal identity and a gem sink — driving IAP conversion through completionist spend.

## Success metrics
- Players can browse and equip free items (Room: Apartment, Outfit: Casual, Mood: Chill)
- Players can unlock premium items by spending gems
- Equipped loadout persists across sessions

## Scope (in)
**Catalog** (hardcoded in Flutter — no DB table):
- Rooms: Apartment (free), Penthouse (50💎), Mansion (120💎), Yacht (200💎), Chalet (150💎), Island (350💎)
- Outfits: Casual (free), Glam (30💎), Streetwear (45💎), Formal (80💎), Fantasy (120💎)
- Moods: Chill (free), Excited (20💎), Dramatic (20💎), Mysterious (35💎), Boss (50💎)

**DB tables:**
- `meta_unlocks(id UUID PK, user_id UUID FK auth.users ON DELETE CASCADE, item_type TEXT CHECK(IN('room','outfit','mood')), item_id TEXT, unlocked_at TIMESTAMPTZ DEFAULT now(), UNIQUE(user_id, item_type, item_id))`
  - RLS: authenticated SELECT/INSERT own rows; no UPDATE/DELETE (unlocks are permanent)
- `user_meta_profile(user_id UUID PK REFERENCES auth.users ON DELETE CASCADE, room_id TEXT DEFAULT 'apartment', outfit_id TEXT DEFAULT 'casual', mood_id TEXT DEFAULT 'chill', updated_at TIMESTAMPTZ DEFAULT now())`
  - RLS: authenticated SELECT/UPDATE own row; no INSERT from client (upserted via Edge Function)

**Edge Functions:**
- `unlock-meta-item` — POST + JWT auth
  - Body: `{ item_type, item_id }`
  - Validates item exists in catalog and has a gem cost > 0
  - Checks not already unlocked
  - Deducts gems from profiles (use existing `profiles.gems` column, UPDATE with WHERE gems >= cost)
  - Inserts into meta_unlocks
  - Returns `{ unlocked: true, gems_remaining: number }`
- `equip-meta-item` — POST + JWT auth
  - Body: `{ room_id?, outfit_id?, mood_id? }`
  - Validates each ID is unlocked (check meta_unlocks OR item cost == 0)
  - Upserts user_meta_profile
  - Returns `{ equipped: true }`

**Flutter — MetaWorldScreen** (replaces MetaPlaceholderScreen):
- Sections: Room picker, Outfit picker, Mood picker — each a horizontal scroll of item cards
- Item card (100×120): emoji/icon, item name, gem cost badge or "✓ Equipped" or "FREE" label
- Locked items: dimmed with 💎N overlay; tap → confirm dialog → calls unlock-meta-item
- Equipped items: pink border glow
- "Save My World" button at bottom (pinkFull gradient, raised) → calls equip-meta-item
- Profile gem balance shown at top (reads from profileProvider)
- On successful unlock: invalidate profileProvider (gem balance updates), show gem deducted toast

**AppShell:** wire MetaWorldScreen into tab index 4 (currently MetaPlaceholderScreen)

## Scope (out)
- No social profile sharing of Meta room
- No animated room preview
- No seasonal/limited items
