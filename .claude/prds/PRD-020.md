# PRD — Discover Screen
**ID:** PRD-020
**Sprint block:** BLOCK 2
**Priority:** P1
**Author:** PM Agent
**Date:** 2026-04-26

## Problem / Why
Players have no way to browse or search the drama catalogue beyond what is featured on the Home screen. A Discover screen is standard for any streaming product and drives series starts, which feeds the energy and progression loop.

## Success metrics
- Players can search dramas by title
- Players can browse dramas by category/genre
- Tapping a drama opens DramaDetailScreen

## Scope (in)
- DiscoverScreen replacing the Discover tab placeholder from PRD-018
- Search bar at top — live filter against series title (client-side filter on the series list; no dedicated search Edge Function needed)
- Category filter chips (horizontal scroll): All, Romance, Thriller, Comedy, Drama, Action — filters series list by genre field
- Drama grid: 3-column poster grid, same PosterCard widget used elsewhere
- Featured row at top: "Trending Now" — top 10 by view_count DESC (reads from existing series table)
- Pull-to-refresh
- Empty state: "No dramas found" illustration + text
- Loading skeleton placeholders

## Scope (out)
- No server-side full-text search (client-side filter sufficient for MVP catalogue size)
- No personalised recommendations
- No "similar to" suggestions
- No voice search

## Data model
Reads existing `series` table (title, genre, poster_url, view_count, episode_count). No new tables.

## API / Edge Functions
None. Uses existing Supabase client query:
```
supabase.from('series').select('*').order('view_count', ascending: false)
```

## Flutter screens / components
- `lib/features/discover/presentation/discover_screen.dart` — full implementation
- `lib/features/discover/application/discover_provider.dart` — FutureProvider fetching all series; AsyncNotifier with search query + genre filter state
- Reuse: `lib/shared/widgets/poster_card.dart` (or equivalent) for grid items
- Reuse: existing series domain model

## Economy / Monetisation notes
Every series start from Discover = energy spend moment. Increases organic energy consumption.
