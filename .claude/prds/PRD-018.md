# PRD — Navigation Restructure + HUD Updates
**ID:** PRD-018
**Sprint block:** BLOCK 2
**Priority:** P0
**Author:** PM Agent
**Date:** 2026-04-26

## Problem / Why
The current bottom nav (Home/Journey/Events/Rank/Rewards) does not match the AppLoop v5 design (Home/Discover/My List/Rewards/Meta). Journey and Rank are content stubs; Events content is surfaced on Home already. The HUD is missing the VIP bar (Drama Pass visual) and inbox icon that appear in the design.

## Success metrics
- Nav matches design: 5 tabs Home/Discover/My List/Rewards/Meta
- VIP progress bar visible in HUD when dramaPassActive == true
- Inbox icon (badge=0) visible in HUD on all tabs
- Events content accessible from Home screen hero card
- Journey accessible from Home screen section
- Rank accessible from Rewards tab (leaderboard button)
- Zero regressions on existing screens

## Scope (in)
- Replace AppShell tabs: Home / Discover / My List / Rewards / Meta
- Meta tab = locked placeholder screen ("Coming Soon — 💎 Meta World")
- Discover tab wires to a placeholder DiscoverScreen (full build in PRD-020)
- My List tab wires to a placeholder MyListScreen (full build in PRD-019)
- HUD: add VIP bar widget below StatusBar — shown only when dramaPassActive == true; fills to 100% width, labelled "DRAMA PASS ACTIVE", uses pink gradient; architect for future `vipTier` int param defaulting to 1
- HUD: add mail icon 📬 to StatusBar right side (replaces or sits beside existing icons), badge shows 0, non-functional tap
- Events hub: add an EventsCard widget on HomeScreen that taps to EventsScreen via go_router push (not a tab)
- Journey map: add a JourneyCard widget on HomeScreen that taps to JourneyScreen via go_router push
- Leaderboard: add a "Rankings" button in RewardsScreen that taps to LeaderboardScreen via go_router push
- All new routes registered in app_router.dart

## Scope (out)
- No changes to EventsScreen, JourneyScreen, LeaderboardScreen internals
- No functional Discover screen (PRD-020)
- No functional My List screen (PRD-019)
- No functional inbox (Sprint 3)
- No Meta World content (deferred)
- No VIP tier progression system (deferred)

## Data model
No new tables. Reads `profiles.drama_pass_active` (already in Profile model).

## API / Edge Functions
