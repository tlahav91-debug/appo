# PRD — My List Series Data Join
**ID:** PRD-022
**Sprint block:** BLOCK 3
**Priority:** P0
**Author:** PM Agent
**Date:** 2026-04-26

## Problem / Why
My List (Continue Watching, Saved, History) currently shows truncated episode/series UUIDs as labels and no poster images, because watch_progress and saved_dramas only store IDs. Players cannot identify their dramas at a glance.

## Success metrics
- Continue Watching cards show series cover_url, title, and episode title
- Saved tab shows real series poster + title in the grid
- History tab shows episode title + series title per row

## Scope (in)
- Update WatchProgressService.fetchInProgress() to JOIN series + episodes:
  `watch_progress join episodes on episode_id join series on series_id`
  Select: watch_progress.*, episodes.title as episode_title, episodes.episode_number,
          series.title as series_title, series.cover_url
- Update WatchProgressService.fetchHistory() with same join
- Update SavedDramaService.fetchSaved() to JOIN series:
  `saved_dramas join series on series_id`
  Select: saved_dramas.*, series.title, series.cover_url, series.total_episodes, series.is_vip
- Create enriched domain models: WatchProgressEnriched, SavedDramaEnriched
- Update MyListScreen to use real cover_url (NetworkImage) and real titles
- Fallback: if cover_url is null → show card-coloured container with movie icon

## Scope (out)
- No personalised recommendations
- No series detail changes

## Data model
No new tables. Supabase supports foreign-table joins via .select() with nested syntax.

## API / Edge Functions
No Edge Functions needed — reads are safe client-side (series + episodes are publicly readable, watch_progress + saved_dramas are RLS-protected to own user).

## Flutter screens / components
- `lib/features/mylist/data/watch_progress_service.dart` — update fetchInProgress + fetchHistory queries
- `lib/features/mylist/data/saved_drama_service.dart` — update fetchSaved query
- `lib/features/mylist/domain/watch_progress.dart` — add enriched fields (episodeTitle, seriesTitle, coverUrl)
- `lib/features/mylist/domain/saved_drama.dart` — add enriched fields (title, coverUrl, totalEpisodes, isVip)
- `lib/features/mylist/presentation/my_list_screen.dart` — replace UUID placeholders with real NetworkImage + titles

## Acceptance criteria
- [ ] AC-1: Continue Watching cards show series cover art (or fallback) and series + episode title
- [ ] AC-2: Saved tab grid shows series cover art and title
- [ ] AC-3: History list shows episode title and completion status
- [ ] AC-4: No UUID strings visible to the user anywhere in My List
- [ ] AC-5: Network images have error fallback (container + icon)

## Dependencies
- PRD-019: watch_progress + saved_dramas tables exist
- Supabase join syntax: `.select('*, episodes!episode_id(title, episode_number, series:series_id(title, cover_url))')`
